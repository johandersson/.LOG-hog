Practical Security For Local Notes

.LOG-hog combines AES-256-GCM encryption, PBKDF2 key derivation, encrypted backups, secure password handling and practical local hardening while preserving a fast and simple writing experience.

Security depends on using a trusted system and choosing a strong, unique password. To help with this, .LOG-hog includes a built-in password generator capable of creating both random passwords and passphrase-style passwords.

Like any local application, .LOG-hog cannot protect against malware, keyloggers or a compromised operating system. It is designed to help protect encrypted notes stored on a trusted machine.
