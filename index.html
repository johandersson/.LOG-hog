Built for Speed. Designed for Privacy.

Most note applications prioritize syncing and sharing. .LOG-hog focuses on something different: helping you capture information quickly while keeping complete control of your data.

⚡ Frictionless Logging

Launch the application and start typing immediately. Save with a shortcut key and continue writing without interruption.

🔒 Security First

AES-256-GCM encryption, PBKDF2 key derivation, secure password handling, backup protection, and tamper-aware integrity mechanisms.

🖥️ Cross Platform

Runs on Windows, macOS, and Linux using Java 17+ with a lightweight footprint and simple deployment.

🔍 Powerful Search

Find information instantly with built-in search, filtering, navigation tools, and markdown rendering.

📦 Tiny & Portable

A compact application that starts fast, consumes minimal resources, and has no external runtime dependencies.

🛡️ Your Notes Stay Yours

No accounts. No subscriptions. No telemetry. No cloud lock-in. Your data lives where you decide.
