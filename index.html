.LOG-hog is a lightweight note-taking application inspired by the classic .LOG functionality in Windows Notepad. Built For Logging, Journaling And Everyday Notes

Most note applications focus on syncing and cloud services. .LOG-hog focuses on writing. Open it, write something, save a timestamped entry, and continue without interruption.

⚡ Inspired By Notepad .LOG

The workflow is inspired by the classic .LOG feature in Windows Notepad. Every entry can be timestamped automatically, making it ideal for journals, development logs and daily notes.

📄 One Encrypted File

Notes are stored inside a single encrypted log file. No databases, cloud storage providers or external services are required.

🔒 Encryption By Default

AES-256-GCM encryption is built into the normal workflow. Encrypted storage is the standard way .LOG-hog operates.

🔍 Search And Browse

Quickly locate entries using integrated search, filtering and markdown rendering.

🔑 Password Generator Included

Strong encryption needs a strong password. .LOG-hog includes built-in random and passphrase generators to help create unique passwords.

🖥 Cross Platform

Runs on Windows, macOS and Linux using Java 17+ while keeping a very small distribution size.

Practical Security, Not Magic Security

.LOG-hog uses AES-256-GCM encryption and PBKDF2 key derivation (600,000 iterations) to protect locally stored notes and backups. Additional protections include encrypted backups, integrity verification, retry delays for failed password attempts and tamper-evident security metadata.


Security depends heavily on the password you choose. Strong encryption cannot compensate for a weak or reused password. To help with this, .LOG-hog includes a built-in password generator capable of creating random passwords and passphrase-based passwords.


Like any local application, .LOG-hog cannot protect against malware, keyloggers, operating-system compromise or attackers who already control your machine. It is designed to provide practical protection for encrypted local notes on a trusted system.

Simple Notes. Local Storage. Open Source.
