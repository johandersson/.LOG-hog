Built for Logging, Journaling and Everyday Notes

Most note-taking applications are built around synchronization and online services. .LOG-hog is built around writing.

Launch the application, write an entry, press Save, and continue. Each entry is timestamped and added to your log, creating a chronological record that remains easy to browse, search and manage over time.

Inspired by the simplicity of Notepad's .LOG workflow, .LOG-hog extends the concept with encryption, search, markdown rendering, backups and practical security features while keeping everything local.

Practical Security, Not Magic Security

.LOG-hog is designed to provide strong, practical protection for locally stored notes while remaining simple to use.

The application uses AES-256-GCM encryption together with PBKDF2 key derivation using 600,000 iterations to help protect notes and backups from unauthorized access.

Additional protections include encrypted backups, integrity verification, retry delays for failed password attempts and tamper-evident security mechanisms.

However, security ultimately depends on the password you choose. A weak, predictable or reused password can undermine even strong encryption. For this reason, .LOG-hog includes a built-in password generator capable of creating both random passwords and passphrase-style passwords.

Like any local application, .LOG-hog cannot protect against malware, keyloggers, operating system compromise or attackers who already control your machine. It is designed to provide practical protection for encrypted notes stored on a trusted system.
